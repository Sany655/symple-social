A social networking web application built with React.js and Firebase, offering real-time features for productivity and community engagement.
Key Features:
📝 Blog System – Browse all blog posts and view detailed blog pages.
🔐 Authentication System – Protected routes with login/register using Firebase Auth.
📰 Feed – Personalized content feed after login.
✅ To-Do List – Create and manage personal tasks.
🗒️ Notes App – Write, edit, and store notes securely.
👥 Friend System – View and manage your friend list.
💬 Inbox Messaging – Chat with friends inside the platform.
🌐 People Discovery – Explore other users on the platform.
📂 File Sharing Tool – Share files publicly without needing an account.
⚙️ Route Guards – Protected and Public components for auth-based routing.
